# 今日の予定（Calender MVP）

就活・友達・ラブで色分けしたカレンダーの MVP です。  
議事録機能はまだ含みません（このリポジトリではカレンダーのみ）。

## 機能

- 上部タイトル「**今日の予定**」と、選択日の予定リスト
- カテゴリ色分け
  - **就活** … インディゴ
  - **友達** … グリーン
  - **ラブ** … ピンク
- 月表示カレンダー（前後月移動・日付クリックで上部リストを切替）
- Excel 風タブ：**全体** / **就活** / **プライベート**
  - 全体 … すべての予定
  - 就活 … 就活カテゴリのみ
  - プライベート … 友達 + ラブ
- デモ用サンプル予定（2026年10月）を同梱

## 必要環境

- Node.js 18 以上（推奨）
- npm

## セットアップと起動

```bash
npm install
npm run dev
```

ブラウザで表示された URL（通常は `http://localhost:5173`）を開いてください。

### その他コマンド

```bash
npm run build    # 本番用ビルド（dist/）
npm run preview  # ビルド結果のプレビュー
```

## 技術構成

- Vite + Vanilla HTML / CSS / JavaScript
- バックエンドなし（サンプルデータは `src/data.js`）
- モバイル向けレスポンシブ UI
